# 桌面录制架构

对应源码版本 0.2.3，2026-10-26 核对。本地现有验收安装包仍为 0.2.2，未包含本次查询修复。已确认的行为缺口见[已知问题](known-issues.md)。

## 边界与查询

`packages/recorder-core` 提供目标、运行、设置等类型、磁盘探测和录制引擎，通过仓储、媒体进程和磁盘接口工作，不依赖 Electron 或旧 JSON 配置。

`apps/desktop/src/main` 组装 SQLite、浏览器查询、串行调度、FFmpeg、系统通知、托盘和生命周期。Vue 通过 preload 暴露的窄接口操作；主进程校验调用来自本地顶层界面，并验证参数。IPC 返回显式的成功或错误结果，渲染进程重建结构化错误，避免跨进程传递丢失诊断字段。

两个 WebContentsView 共用 `persist:xhs-account`。前台观看官方网页，是唯一登录及验证入口；隐藏且静音的网页按需加载网站签名环境，不附着到可见窗口。远程页面没有应用 preload，禁用 Node，开启沙箱、上下文隔离和网页安全；只允许官方 HTTPS 顶层地址。

`SignerRuntime` 从网站当前请求处理链中获取每次查询的实时签名头与最终请求字节，校验接口地址、关键词和业务类型，只接收允许的请求头。签名仅在内存中使用，不保存或重放为长期凭据。主进程的 `net.request` 使用同一 Session 和 `credentials: 'include'` 请求 onebox 接口，Referer 仅含网站 origin。跳转采用手动处理，遇到验证入口取消请求并提供前台恢复操作；后台查询不导航观看页。

首次读取持久化凭据只建立基线，不增加会话版本，不解除已保存的查询限制。其后会话 Cookie 或到期时间改变时，旧查询被取消，签名环境重置；迟到响应按会话版本丢弃。真实登录变化后的验证是一次只读搜索，可以在监听暂停或尚未添加目标时执行，不由该探测直接启动录制，且遵守限流冷却。未受限账号的正常启动监听检查保留。

交互式搜索与主页添加单独保存操作 ID、关键词及可选的主页用户 ID。未完成操作优先用于无目标范围的重试，指定目标的重试仍只检查该目标。重试及登录恢复结果按操作 ID 写入 `candidateSearch` 快照，并通过 IPC 返回给界面；旧后台查询即使关键词相同也不能消费新操作，避免错误清除待恢复状态。候选结果只在对应操作完成时更新，后续普通状态推送不会重复填回已清空的添加列表。

## 调度与错误

每个目标独立计算下次检查时间：未开播 120 秒；直播中且有启动、录制或重连任务时 300 秒；其余状态使用设置间隔，默认 120 秒。调度每秒检查到期目标，请求始终串行；请求间隔默认随机 5–15 秒，设置的下限至少为 5 秒，上限为下限的 3 倍。手动查询共用队列。

错误包括登录失效、验证、访问限制、限流、签名、签名环境、网络、超时、接口结构、身份匹配及未知错误。HTTP 403/406/461 或明确无权访问归为 RESTRICTED，不直接推断登录失效。阻止类型保存到账号状态，暂停常规自动查询；429 至少冷却 60 秒并遵守更长的 Retry-After。只有有效业务响应才清除账号级查询错误，不清除其他目标的网络错误或磁盘、输出、手动停止阻止。

结构化错误含中文说明、恢复建议、发生时间和诊断编号；复制诊断仅输出允许字段，并脱敏凭据、账号、网址和私人路径。`browser.log` 记录动作和结果摘要，不写请求头、响应原文或查询账号；目前持续追加，尚无日志轮转。

候选用户经 ID 确认后才能添加，后续结果必须匹配该 ID。通知通过 `live_sessions(targetId, roomId)` 去重。未知结果或查询失败保留上次明确状态，界面同时显示确认时间。

录制自然 EOF 或重试耗尽后产生一次流结束事件。服务按运行 ID 去重、按目标 generation 保存待确认项，在引擎收尾后进入查询队列；监听暂停时保留待确认项。手动停止、归档、退出和磁盘保护不会产生该事件。

## 存储与恢复

SQLite 包含 `settings`、`targets`、`tasks`、`runs`、`files`、`live_sessions`、`notices`、`account`、`query_errors`。使用 WAL、外键、busy timeout 和事务迁移，拒绝较新数据库版本。

版本 2 增加归档时间、目标 generation、错误类别和最后明确确认时间。归档先禁止新工作再收尾任务，历史外键及分片保留；重新添加恢复同一目标并递增 generation。排队前、请求执行前、响应后及数据库更新均校验代次，避免迟到响应覆盖新状态。

版本 3 增加 `query_errors`，保存账号及目标范围的结构化诊断，保留已有设置、目标和录制历史，不保存登录 Cookie 或签名。应用使用 Electron `userData`；开发工具的 Windows 文件虚拟化可能使观察工具读取另一份资料，验收须核对实际运行实例、日志来源和资料目录。

启动时把未结束的运行标为中断，再核对分片和已索引文件的存在状态。当前界面列表及分片恢复扫描共用最近 500 条记录的查询，尚无历史分页；旧文件不会因此删除，但较早记录和未索引分片可能无法从界面或启动扫描找回。

## 录制与合并

录制在第一次异步操作前预占目标，防止重复进程。任务标识来自平台、用户 ID 和房间 ID；每次运行使用独立 UUID、工作目录及分片名称。同房间可以产生多个独立运行。

默认源流复制、30 分钟分片，可选择转码。FFmpeg 隐藏启动，通过标准输入 `q` 温和停止，10 秒后强制终止。录制前、运行中和合并前检查实际输出盘；空间不足或不可写时保留分片，处理后由用户恢复。同主播任务替换时的磁盘探测竞态仍待修复。

0.2.2 为合并增加独立取消状态。自然结束或已进入合并时，下播观察等待当前收尾，不能中断合并。录制阶段手动停止仍可正常合并；合并阶段用户停止、退出或磁盘故障可以取消，取消后即使 FFmpeg 返回 0 也不发布残缺成品、不删除原分片。单分片复制、多分片准备、手动重试扫描及发布前均检查取消状态。

合并临时文件位于本次工作目录，成功后重命名为成品；清理只针对本次已索引分片，失败保留。退出时取消新查询与新任务，收尾媒体进程，等待网页存储和日志写入，再关闭数据库。关闭自动合并后，当前界面缺少正常完成任务的手动合并入口。

## 观看与发布

观看、查询和录制互相独立。专注观看隐藏外围 UI，顶部恢复栏和原生网页视图分别布局；Esc 优先退出网页全屏，再退出专注观看。关闭到托盘时临时静音，显示窗口后恢复原静音状态；最小化保留任务栏按钮。

Windows NSIS x64 包包含 Electron 39.8.10、ABI 140 的 `better-sqlite3` 和 FFmpeg。原生模块从 asar 解包，FFmpeg 位于 resources。仅打包桌面输出和运行依赖，排除开发数据库、Session、诊断原件及录制样本；旧命令行入口已移除。

当前本地验收包为 0.2.2，未签名；已完成保留数据换装核验。代码签名、干净机器安装、自启动、系统通知点击及其他真实异常场景仍属交付前待完成项。历史结果分别见 [0.2.0 验收](browser-validation.md)、[0.2.1 查询观察](query-recovery-validation.md)和 [0.2.2 合并修复](superpowers/plans/2026-10-13-merge-interruption.md)。
