Windows x64、Electron 39.8.10、SQLite 3.51.2、FFmpeg 6.1.1。历史查询实现通过网站搜索页和响应观察工作，该实现已由后续版本替换。

| 直播账号的查询及官方直播网页播放 | 通过，视频尺寸和播放进度符合预期 |

## 真实录制

- 对真实直播流完成两次独立 FFmpeg 录制；为验证分片临时缩短分片间隔，测试后恢复设置。
- 两次运行使用独立输出；观看、最小化、隐藏到托盘期间录制继续，手动停止后合并完成。
- 隐藏观看页临时静音、恢复窗口后恢复原静音状态通过。
- 两份合并文件均通过全文件 FFmpeg 解码，退出码 0、无错误输出。尚未据此判定外部播放器音画同步验收通过。
- 录制样本、分片及数据库保留在本机，不进入 Git 或安装包。
