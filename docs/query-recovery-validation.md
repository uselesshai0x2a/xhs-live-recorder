## 实现范围

- 保留原用户数据和 `persist:xhs-account`；观看页作为唯一登录及验证入口，移除后台查询页切换。
- 隐藏网页提供网站当前签名运行环境，通过网站自身请求处理链取得每次查询的完整签名及最终请求字节，不保存或重放长期签名。
- 主进程使用同一 Session 的 `net.request` 发请求，采用 origin 级 Referer，应用不主动覆盖 User-Agent 或重置设备标识。采用 ClientRequest 手动跳转事件识别验证入口并取消请求。
- 会话变化取消旧请求、重建签名环境，并合并一次只读验证；只有成功业务响应才显示查询可用。
- 结构化错误区分登录、验证、访问限制、限流、签名、网络及接口变化。IPC 显式封装错误，复制诊断仅输出允许且脱敏的字段。
- 数据库升级到版本 3，增加诊断表，保留原目标、设置、录像和历史；迁移前做本机备份。
- 专注观看隐藏外围界面，顶部恢复栏与原生网页视图分别布局，保留网页加载和声音状态；Esc 优先退出网页全屏。
